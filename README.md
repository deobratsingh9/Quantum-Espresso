# Quantum-Espresso
Quantum ESPRESSO workflows for electronic band-structure calculations using GGA-PBE and Hybrid HSE06, including input setup, output analysis, and Python band plotting.

This repository provides a step-by-step workflow for calculating and comparing electronic band structures using GGA-PBE and Hybrid HSE06 functionals within Quantum ESPRESSO.

The project covers input file preparation, SCF/NSCF band-structure calculations, output analysis, and Python-based band plotting, enabling accurate comparison of band gaps and electronic dispersion for semiconductors and 2D materials.

✨ Features

⚛️ GGA-PBE and Hybrid HSE06 band-structure calculations

📐 High-symmetry k-path generation for band structures

💻 Quantum ESPRESSO input templates (SCF, NSCF, Bands)

🔬 Analysis of QE output files and eigenvalues

📊 Python scripts for band-structure visualization

📈 Direct comparison of PBE vs HSE06 band gaps
